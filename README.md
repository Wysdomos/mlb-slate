# MLB Slate — Daily Format v3.0

Mobile-friendly interactive MLB slate analysis with HR boards, K props, conviction picks, and live sportsbook links.

**Live site:** https://wysdomos.github.io/mlb-slate/

## Features
- 🟢 Green = Tier 0 / great picks
- 🔴 Red = Skip / BAD grades
- ⭐ Tap-to-pick: build your daily card, saved on-device
- 🔍 Search + filter chips (Tier 0, Hot, Cold, Skip, My Picks)
- 📲 Add to home screen (PWA)
- 🌗 Light/dark mode
