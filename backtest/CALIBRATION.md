## Reading this honestly

A bucket only means something once n clears ~30; below that the interval says more than the point estimate. If a high-consensus bucket does not clearly beat a low one, the consensus signal is not separating -- that is a finding, not a failure. This report is the gate for the XGBoost question: models only earn a seat if these buckets leave measurable room.
